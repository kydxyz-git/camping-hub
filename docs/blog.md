# 네이버 블로그 작업 안내서 (261030)

블로그 **'공대남자의 캠핑 기록'**(닉네임 공대남자) 글을 만드는 표준 절차. **PC의 Claude(데스크톱 앱·Code)에서 작업한다** — 사진 원본이 PC에 연결된 네이버 MYBOX 폴더에 있어서 (사용자 결정 261030).

목표: 캠핑 주제로 글을 꾸준히 쌓아 **네이버 인플루언서(캠핑) 신청** — 15~20개쯤 쌓이면 신청 검토.

## 한 번에 보는 흐름

1. 사용자가 "OOO 블로그 글 만들어줘"라고 하면
2. `data/camps.json`에서 그 캠핑장을 읽고 **원고를 쓴다** (아래 '글 쓰는 규칙')
3. MYBOX 폴더에서 그 캠핑장 사진을 **직접 보고 고른다** (아래 '사진 고르기')
4. 원고 JSON을 `_blog/{캠핑장 이름}.json`으로 저장 → `python tools/blog_post.py _blog/{이름}.json --serve`
5. 열린 페이지에서 사용자가 **'다음 복사' → 네이버 에디터에 Ctrl+V**를 반복 (창 두 개 나란히)
6. 발행 후 맨 아래 '올린 글 기록'에 한 줄 추가

`_blog/`는 `.gitignore` — **사진·원고·만든 페이지는 저장소에 올리지 않는다** (공개 저장소).

## 왜 이 방식인가 (바꾸지 말 것)

- 글 속 사진을 HTML로 붙여넣으면 네이버가 **사진을 올리지 않고 링크만 건다** (kydz.kr 주소 그대로 — 261030 확인). 링크 사진은 홈페이지 사진이 바뀌면 깨지고, 남의 사진을 끌어온 글로 보여 노출에 불리. → **사진은 반드시 '사진 그대로' 클립보드로 붙인다** = `blog_post.py`의 '다음 복사'.
- 네이버 블로그 글쓰기 API는 없음. 브라우저 자동 조작으로 글을 올리는 건 **금지** — 쓰레드처럼 봇으로 걸릴 위험(261030 쓰레드 봇 분류 사건).

## 글 쓰는 규칙

- **사실은 데이터에서만**: `camps.json`의 `story`(본인 글)·`notes`(메모)·`info`·`address`·`checkin`/`checkout`·`extras`·`visits`·`visit_log`·`guide`, 그리고 사용자가 채팅에서 말한 것. 없는 사실·숫자·시설·가격을 지어내지 않는다. 확실치 않으면 빼거나 사용자에게 묻는다.
- 방문 횟수는 `visits` 기준 (`story` 속 숫자와 다르면 사용자에게 확인 — 봉화별: story 28 / visits 29 → 29가 맞음).
- 말투: `story`처럼 1인칭 '~요/~습니다' 섞인 편한 블로그체. 첫 줄 "안녕하세요, 5년차 부부캠퍼 공대남자입니다." 아내는 '와이프'.
- 빼는 것: 협찬 고지 외의 광고 톤("강력 추천!" 남발), DM 유도, 할인·이벤트, '이번에/올해/내년' 같은 시점 표현, 가격.
- **협찬받은 곳·장비는 글 맨 위에 협찬 고지** (공정위 표시 의무).
- 구성 (첫 글 봉화별캠핑장 기준):
  1. 인사 + 이 캠핑장을 한 줄로 (방문 횟수 같은 훅)
  2. `📍 {이름} 기본 정보` — 주소·입퇴실·이용 조건(노키즈·인원·애견)·운영 시기 → 바로 아래 지도
  3. `■ 소제목` 3~5개 — 자연/사이트, 분위기(비·밤·계절), 시설·관리, 언제 가면 좋은지, 예약 팁
  4. `■ 이런 분께 추천해요` 목록 + 주의(노키즈 등)
  5. 마무리 한 줄 + `▶ 공대남자 캠핑장 모음: https://kydz.kr/camps/{이름}/` + `▶ 인스타그램: @kyd_zm`
- 분량: 본문 1,500~2,500자, 사진 8~15장. 캠핑장 이름은 제목·첫 문단·소제목·마무리에 자연스럽게 4~6번.
- 제목: `{이름} 후기 | {훅} {지역} {특징} 캠핑장` (예: `봉화별캠핑장 후기 | 4년간 29번 다녀온 경북 봉화 계곡 캠핑장`)
- 태그 15개 안팎: 이름, 지역+캠핑장, 특징(계곡·노키즈·애견동반…), 계절, `#캠핑장추천 #캠핑장후기 #부부캠핑`.
- 카테고리: 캠핑장 후기 / 캠핑 장비 / 캠핑 요리 / 캠핑 꿀팁 / 여행지.
- 그 캠핑장 네이버 클립이 있으면 본문 중간에 넣으라고 사용자에게 알려 준다 (클립 앱에서 올린 클립은 블로그에 자동으로 안 나옴 — 클립 쪽엔 '블로그 스티커'로 이 글을 연결).

## 사진 고르기 (MYBOX 폴더)

- MYBOX 폴더 위치·구조는 처음 한 번 사용자에게 묻고 여기에 적어 둔다: `(아직 미정)`
- 그 캠핑장 방문 사진에서 **직접 열어 보고** 고른다. 파일 이름만 보고 고르지 않는다.
- 순서: 대표(썸네일용) → 사이트·전경 → 소제목 내용에 맞는 사진(계곡·밤·계절…) → 마무리(밤/분위기).
- 소제목 내용과 안 맞는 사진을 억지로 넣지 않는다 (예: 샤워실 사진이 없으면 그 섹션은 사진 없이).
- 피할 것: 얼굴이 크게 나온 다른 사람, 차 번호판, 흔들리거나 어두운 사진, 거의 같은 사진 연속.
- 홈페이지 사진(`images/camps/`)은 600×750으로 작음 — MYBOX 원본이 없을 때만 대신 쓴다.

## 원고 JSON 형식

```json
{
  "slug": "봉화별캠핑장",
  "title": "봉화별캠핑장 후기 | 4년간 29번 다녀온 경북 봉화 계곡 캠핑장",
  "category": "캠핑장 후기",
  "tags": "#봉화별캠핑장 #봉화캠핑장 #경북캠핑장 #계곡캠핑장 #노키즈캠핑장 #캠핑장추천 #캠핑장후기",
  "thumb": {"photo": "D:/MYBOX/캠핑/봉화별/IMG_1234.jpg", "name": "봉화별캠핑장", "sub": "경북 봉화 · 4년간 29번 방문", "focus_y": 0.5},
  "blocks": [
    {"p": "안녕하세요, 5년차 부부캠퍼 공대남자입니다.\n첫 캠핑장 기록은 …"},
    {"h": "📍 봉화별캠핑장 기본 정보"},
    {"p": "· 주소: 경북 봉화군 소천면 구마동길 513-127\n· 입실 13:00 / 퇴실 12:00"},
    {"map": "봉화별캠핑장"},
    {"h": "■ 숲에 푹 파묻힌 사이트, 1급수 계곡"},
    {"img": "D:/MYBOX/캠핑/봉화별/IMG_1240.jpg"},
    {"p": "봉화별캠핑장의 사이트는 …"}
  ]
}
```

- `p` 글(줄바꿈 `\n`, 빈 줄 = 문단 사이) · `h` 소제목(굵게) · `img` 내 PC 사진 경로(웹 주소 금지 — 스크립트가 막음) · `map` 지도 넣을 자리 안내.
- `thumb`: 썸네일 1080×1080 (위 사진 + 아래 남색 띠에 `name`·`sub`, 오른쪽 아래 '공대남자의 캠핑 기록'). `focus_y` 0~1로 사진 위아래 위치 조정. 블로그 타이틀(열기구 밤 사진)과 같은 남색 톤.
- 사진은 긴 변 1600px로 줄여 JPEG로 저장. 결과물 `_blog/{slug}/` (`post.html`, `00_대표.jpg`, `01.jpg`…).

## 붙이는 법 (사용자 안내용)

1. 네이버 블로그 글쓰기와 `post.html`을 **창 두 개로 나란히**
2. **제목 복사** → 제목 칸
3. 본문 맨 위 클릭 → **다음 복사 ▶** → 에디터 Ctrl+V → 다시 다음 복사 … (조각마다 몇 번째인지 표시, 잘못 붙였으면 그 칸을 눌러 그 조각부터)
4. `[지도: …]` 줄 자리에 에디터 '장소' 버튼으로 지도 넣고 그 줄 삭제
5. 첫 사진(썸네일)을 대표 사진으로 · 카테고리 · **태그 복사** → 태그 칸 · 발행
- `post.html`을 그냥 열었을 때 복사가 막히면 `--serve`로 연다 (localhost).
