개인정보처리방침

시행일: 2026년 11월 10일

“AI 시말서” 앱(이하 “앱”)은 유튜브 채널 AI 시말서 운영자가 자기 채널의 통계를 보고, 운영자 채널에 영상을 올리기 위해 쓰는 내부 도구입니다.

1. 사용하는 정보

앱은 Google 계정 로그인(OAuth)으로 운영자가 허용한 범위에서 YouTube API 서비스를 통해 다음 정보에 접근합니다.

  • 운영자 채널의 기본 정보와 영상 목록(YouTube Data API)
  • 운영자 채널의 조회수·시청 시간·시청 지속률 같은 통계(YouTube Analytics API)
  • 운영자가 허용한 경우, 운영자 채널에 영상과 그 정보(제목·설명·자막)를 올리는 권한

다른 사용자나 시청자의 개인정보는 수집하지 않습니다.

2. 쓰는 목적

받은 정보는 운영자 채널의 성과를 정리하고 영상을 올리는 데만 씁니다. 광고, 판매, 다른 서비스 제공에 쓰지 않습니다.

3. 저장과 공유

통계와 로그인 토큰은 운영자 본인의 컴퓨터에만 저장합니다. 제3자에게 팔거나 넘기지 않습니다.

4. 권한 철회와 삭제

Google 계정의 보안 › 타사 앱 액세스에서 언제든 앱의 접근 권한을 철회할 수 있습니다. 철회하면 저장된 토큰은 더 이상 쓸 수 없고, 운영자는 컴퓨터에 남은 데이터를 지웁니다.

5. YouTube 및 Google 정책

앱은 YouTube API 서비스를 사용합니다. YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용됩니다. 앱의 Google API 사용은 Limited Use 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.
